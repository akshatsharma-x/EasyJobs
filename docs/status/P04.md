## How to run

```bash
pnpm --filter @easyjobs/registry typecheck
pnpm --filter @easyjobs/registry test
pnpm --filter @easyjobs/registry detect razorpay.com             # → {"ats":"greenhouse","token":"razorpaysoftwareprivatelimited"}
pnpm --filter @easyjobs/registry detect --candidates             # careers pages → data/discovery/detect.json
pnpm --filter @easyjobs/registry probe                           # slug probing → data/discovery/probe.json
pnpm --filter @easyjobs/registry verify                          # → companies.json, rejected.json, summary.md
pnpm --filter @easyjobs/registry verify --only workday           # re-verify one ATS; --slug a,b; --fresh; --skip workday
```

Run the scripts with `NODE_TLS_REJECT_UNAUTHORIZED` unset (it is set to `0` in this machine's shell; not needed).

## Decisions

- **One entry per company, slug = `slugify(name)`** (matches P03's `companySlug`); other live boards go to
  `extra.altBoards`. Legal entities / former names go to `extra.aliases` and the exported `aliases`
  (curated table in `src/aliases.ts` + candidate `aka`).
- **A board must belong to the company**: website/job-URL domain evidence first, then name. Conflicting domain
  evidence beats a same-name match (`circleci.com` ≠ Circle); a board naming another company is rejected even if its text
  mentions ours; empty boards can't be matched on name alone (Workable answers `200 {"name":"Visa","jobs":[]}` for
  never-used accounts). Tenants of vendor hosts must resemble the company (`synopsys.avature.net` is not Ansys), except
  Oracle pods, which are random (`iaziqy.fa.ocs.oraclecloud.com` = Uber). Curated hints are exempt (`ghr` = BofA).
- **Trust order** per company: link on its own careers page > curated hint > name-matched probe > page markers >
  Workday/Eightfold probes > previous entry > the careers page as `custom`. A board with a real job API beats page-only
  platforms; a ≥ 5× bigger live board wins over a small one; sub-portals (events, military hiring, talent communities)
  never win.
- **P09 overlap**: the 15 companies with enabled `@easyjobs/scraper-bigtech` scrapers are `ats: "custom"` with P09's
  slugs (`extra.scrapedBy`) so ATS adapters don't double-crawl them (e.g. Accenture also has a 64k-job Workday site);
  for P09's 6 disabled scrapers a real board is used — Uber is now Oracle (857 jobs), Cognizant its JSON-LD site.
- **Priority 3 for empty boards** and for companies with neither India presence nor remote hiring.
- **Politeness**: robots.txt for every HTML page (careers pages, Lever/Ashby board pages); `robots: false` only for the
  documented public job APIs. jobs.ashbyhq.com disallows `/api/`, so Ashby's GraphQL is never used. Per-ATS gates
  (≤ 4 in flight; Workday 1 per 3 s; Workable 1 per 1.5 s; Oracle/Eightfold 2 at a time), a 429 circuit breaker
  (10-min family cool-down, open after 3 strikes; a careers site answering 429 is skipped), caches in `.cache/`.
  Bot walls, tarpits and 403s were respected, never worked around.

## Known gaps

1. **Workday is unverified (272 entries)** — Workday's Cloudflare started answering 429 to Node's fetch from this machine
   at 22:30 UTC, right after my first probing burst (~2 req/s across tenants for under a minute, before the Workday
   gate existed), so **my probing likely contributed to the block that also hit P08's Workday runs** (their 22:32 run
   logged 13× 429). It still blocked even `robots.txt` at 23:43 UTC; curl from the same IP was unaffected (client
   fingerprint + IP scoring). I didn't work around it. The 272 Workday tokens come from careers-page links or curated
   hints and are kept as `verifiedBy: "unverified"`, `verifiedAt: null`, `extra.pendingReason`. **When Workday answers
   again: `pnpm --filter @easyjobs/registry verify`** (everything else is cached; Workday runs at 1 request/3 s, about 15 min)
   promotes them with `openJobs`, `extra.indiaJobs` and `extra.workdayIndiaFacet` (India-only crawl facet for P08).
   Expect roughly +250 API-verified entries.
2. **Workable** throttled at ~2.5 req/s and stayed throttled, so only part of the candidate list was probed on Workable
   (7 boards). `probe --retry --ats workable --base-only` can finish it later.
3. **Bot-protected careers sites**: 419 sites were unreachable politely (Akamai-style tarpits on many large Indian sites
   — Zomato, MakeMyTrip, PolicyBazaar, HDFC; 403s — Revolut, Indeed, Zetwerk, UST; robots — Goldman Sachs). The most
   important are kept as curated, unverified `custom` portals; 239 rejected candidates had no reachable page or board.
4. Some entries are page-only platforms (122) whose job counts are unknown, and a few boards are regional (e.g. Bayer's
   Nordic Teamtailor) because that's what the company links.
5. `extra.workdayIndiaFacet` / `extra.indiaJobs` only appear after Workday verification. Contract ideas (aliases field,
   multiple boards, Greenhouse EU tokens, a verification status) and consumer notes are in `docs/contract-requests/P04.md`.
