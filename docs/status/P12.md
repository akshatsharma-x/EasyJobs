## How to run

```bash
pnpm --filter @easyjobs/scraper-open-apis scrape --limit 30                  # all enabled sources → out/<id>.jsonl
pnpm --filter @easyjobs/scraper-open-apis scrape --scraper unstop --limit all
pnpm --filter @easyjobs/scraper-open-apis test                               # 182 offline tests
LIVE=1 pnpm --filter @easyjobs/scraper-open-apis test                        # + 11 live smoke tests (keyed ones skip without keys)
LIVE=1 LIVE_SKIP=remotive pnpm --filter @easyjobs/scraper-open-apis test     # spare Remotive's ≤4 calls/day budget
pnpm --filter @easyjobs/scraper-open-apis typecheck
```

## Env vars

All are optional and documented in `packages/scrapers/open-apis/.env.example` and its README.

- **Keys:** `ADZUNA_APP_ID`, `ADZUNA_APP_KEY`, `JOOBLE_API_KEY`. Optional `THEMUSE_API_KEY` and `HIMALAYAS_API_KEY` only raise rate limits.
- **Tuning:**
  - Page caps: `UNSTOP_MAX_PAGES`, `ADZUNA_MAX_PAGES`, `HIMALAYAS_MAX_PAGES`, `ARBEITNOW_MAX_PAGES`, `JOBICY_MAX_PAGES`, `THEMUSE_MAX_PAGES`, `JOOBLE_MAX_PAGES`.
  - Queries and feeds: `JOOBLE_KEYWORDS`, `ADZUNA_WHAT`, `JOBICY_GEOS`, `WWR_FEEDS`.
  - HN: `HN_RESOLVE_LINKS`, `HN_RESOLVE_MAX`, `HN_PREVIOUS_THREAD_DAYS`.
- **Ops:**
  - `OPEN_APIS_DISABLED`: per-source kill switch (`remoteok,jobicy` or `all`).
  - `OPEN_APIS_CACHE_DIR`: redirect cache location (`off` disables it).
  - `OPEN_APIS_HTTP_CACHE_MIN`: dev-only response cache.
  - `OPEN_APIS_PAUSE_SCALE`: tests only.

## Decisions

- **Terms beat redirect resolution.** `applyUrl` is resolved to the final URL only for HN links, where it is cheap and allowed. One HEAD per link goes through the shared polite client (robots.txt on), cached for 30 days in `.cache/redirects.json`, with login walls rejected. It is deliberately *not* resolved for:
  - Adzuna: `redirect_url` is a paid click tracker, so bot resolution would mean fake clicks.
  - Jooble: `/desc/` and `/away/` are robots-disallowed.
  - Remotive and Remote OK: their terms require their own URL.
  - Himalayas: "applicationLink unchanged".
  - Jobicy: "redirect to the original job URL provided in this feed".
  - WWR: the apply link is behind sign-in, and we never log in.
  - Unstop: applications happen on Unstop.
- **Display terms are recorded per job** in `extra.terms`, so W1/W2 can honour them:
  - Remotive and Himalayas forbid resubmitting their jobs to Google Jobs or as JobPosting JSON-LD.
  - Remote OK requires a *followed* link (no `nofollow`).
  - Contract request #1 asks to make these first-class fields.
- **robots.txt:** kept on wherever robots allows the path (Unstop `/api/public/*`, Remote OK, Arbeitnow, Jobicy, WWR, The Muse, Algolia). `robots: false` (§0.8: documented JSON APIs) is used only for Remotive (robots disallows `/api/*`, but the API's legal notice grants access), Himalayas (robots pattern-blocks `?page=` while its docs instruct paging), Adzuna (`Disallow: /` on the keyed API host) and Jooble (POST API).
- **Sweeps:** `target` is non-null only when a run sees the whole feed (`remotive`, `whoishiring`, `unstop:jobs`, `unstop:internships`; Unstop falls back to null if the page cap is below `last_page`). Windowed or paged feeds use `null`. See contract request #2.
- **HN:**
  - One job per role.
  - The previous month's thread is also read during the first 7 days of a new one, skipping companies that reposted, so the monthly switch doesn't close everything at once.
  - The 360-minute interval was given by the spec.
- **Unstop eligibility:**
  - Passout years count only for eligible sectors, because Unstop keeps stale picklist values.
  - Course codes are read from top-level and nested `professionalEligibility`/`fresherEligibility` blocks and mapped to readable degree names. Specialisations go to `extra.specializations`.
- **Adzuna predicted salaries** are never put in `salary`; they go to `extra.predictedSalary`.
- **Jooble 64-bit ids** are quoted before `JSON.parse`, so they stay exact.
- **Secrets** never appear in errors or logs. Keys are redacted from every error. Jooble's key is in the URL path, so the shared client's retries (whose log line prints the path) are disabled for it, and the scraper retries itself with redacted logs.
- **Politeness:** sequential paging with documented gaps (Jobicy ≥ 1 s, Arbeitnow 1.5 s, Adzuna 2.5 s, Himalayas 2 s without a key), plus the shared client's per-host limits. A Cloudflare challenge raises `SourceBlockedError` and is never retried or bypassed.
- **Privacy:**
  - HN usernames are never stored.
  - Job-seeker posts and posts whose "company" is a person's name are skipped. Recruiter posts credit the employer named after "@".
  - Personal-looking email addresses in HN post text are replaced with "[email in original post]"; role mailboxes (careers@, jobs@, …) are kept. After the change, the live HN output contains only role mailboxes.
  - LinkedIn `/in/` profile links are never used as apply links.
  - Fixtures are scrubbed (usernames, emails, phone numbers; the two personal posts are anonymised).

## Known gaps

1. **The Muse is blocked here.** Every request, including its developer docs page, returns `403` with `cf-mitigated: challenge` (Cloudflare edge `…-DEL`), whatever the user agent. The scraper follows the documented v2 API (`page`, `level` ×4, `location`, `descending`, optional `api_key`) and is fixture-tested with a synthetic fixture. It raises `SourceBlockedError` cleanly and may work from other networks. Verify there.
2. **Adzuna and Jooble weren't exercised live** (no keys). Their fixtures are synthetic, built from the documented formats. Jooble's docs page is also behind Cloudflare from here, so the request fields (`ResultOnPage`, `datecreatedfrom`) come from its published REST docs. Run `LIVE=1` once keys exist.
3. **Region filtering is heuristic.** It is tuned on today's feeds, with table tests for the patterns seen. Some US-only roles labelled "Worldwide" without saying so (e.g. some Carrot rows) still pass.
4. **HN parsing is heuristic.** 32 posts got an inferred title ("Multiple roles") because neither the header nor body bullets named a role. A few location strings keep notes such as "London (and New York for US AE)". Salary stays as `salaryRaw` for the normalizer.
5. **Himalayas coverage** is the newest ~200 India-eligible jobs per run (10 pages, no key) out of ~6.8k. Raise `HIMALAYAS_MAX_PAGES` with an API key.
6. **Remotive budget:** this session made 5 calls to Remotive today (2 while exploring, 1 CLI run, 2 LIVE runs), one over its advisory "max. 4 times a day". In production the 360-minute schedule makes exactly 4/day. Use `LIVE_SKIP=remotive` for repeated LIVE runs.
