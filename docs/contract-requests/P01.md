# P01 (web): contract and root requests

Nothing in the contract blocked the web app. These are requests for W1 or P02, highest value first.

1. **Endpoint for reporting a listing** (new): `POST /v1/jobs/:id/report` with body `{ "reason": string, "details"?: string }`, answering `202 { "ok": true }`. It should be rate-limited, with no auth. The web app's Report dialog currently stores reports in `localStorage` (`easyjobs:reports`). Wiring it up is one call in `apps/web/src/components/jobs/report-dialog.tsx`.

2. **Company logos in facets.** `FacetBucket` for `facets.company` has no `domain` or `logoUrl`, so the web app calls `GET /v1/companies?pageSize=100` to put logos and names on the company filter, chips and smart-search detection. Either option would remove that call:
   - add an optional `meta?: { domain: string | null; logoUrl: string | null }` to `FacetBucket`, or
   - support `GET /v1/companies?slugs=a,b,c`.

   **Please make sure `/v1/companies` accepts `pageSize` up to 100**; the contract doesn't state a maximum.

3. **`GET /v1/suggest` with an empty `q`.** The web app shows "popular" companies and roles when the search box gets focus by calling `suggest("")`. Please return popular items for an empty `q` instead of an empty result or a 400. The mock does this.

4. **Optional `byCategory` in `StatsResponse`** (`Record<JobCategory, number>`). The home bento currently reads category counts from `facets.category` of a `pageSize: 1` search, which works but costs a search query.

5. **Optional stream event for closed jobs:** `{ type: "closed"; id: string }`. Live lists could then drop jobs that close while someone is watching. Closed jobs already disappear on the next fetch.

6. **Root `pnpm-workspace.yaml`.** pnpm 12.23 ignores `onlyBuiltDependencies`, so every `pnpm add` or `install` ends with `ERR_PNPM_IGNORED_BUILDS: esbuild@0.28.2` (exit code 1). The packages are still installed, and esbuild works without its postinstall. Suggested fixes:
   - switch to the pnpm ≥ 11 form, `allowBuilds: { esbuild: true, sharp: true }`, and
   - pin `"packageManager": "pnpm@12.23.0"` in the root `package.json` so every session uses the same pnpm.

7. **Ports on this machine.** `:4000` is taken by an unrelated app (`~/Downloads/temp5/outbox/backend`), and `:3000` by another Next.js app. Please check them before starting `apps/api` and `apps/web`.
